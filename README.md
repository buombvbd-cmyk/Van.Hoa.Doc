# Văn Hóa Đọc

Ứng dụng cộng đồng đọc sách bằng Flask.

## Đăng nhập quản trị ban đầu
- Tài khoản: `admin`
- Mật khẩu: `Admin@123`

## Chức năng
- Tài khoản do admin cấp
- Chia sẻ ảnh trang sách
- Video, file và URL
- Newfeed cuộn dọc kiểu TikTok
- Like
- Bình luận mở ngay trên bài, không chuyển trang
- Trang quản trị cấp tài khoản và xóa bài
